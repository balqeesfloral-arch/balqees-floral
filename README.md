# Balqees Floral — النسخة الاحترافية

- جميع الملفات والصور في المجلد الرئيسي نفسه.
- لا توجد مجلدات داخلية مطلوبة.
- أسماء الصور عشوائية لتجنب مشاكل GitHub Pages وحساسية المسارات.
- تصميم متجاوب للكمبيوتر، اللابتوب، التابلت، الجوال، والشاشات الصغيرة.
- صورة الغلاف مقصوصة لإظهار تنسيق الزهور فقط.
- تمت إضافة تنسيق الحدائق، رمز واتساب، عبارة ترحيبية، وتحسين بطاقة حفظ معلومات التواصل.
- روابط إنستقرام وتيك توك موجودة في الشريط العلوي باللغة العربية.
