# بلقيس PRO MAX — FINAL

هذه النسخة تجمع **تطوير PRO MAX الجديد** مع **صور الموقع القديمة كما هي وبنفس أسمائها**.

## ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages
يجب أن يكون `index.html` في الجذر مباشرة.

## الصور
كل الصور الموجودة في النسخة السابقة جُمعت في:
`images/`
بدون تغيير أسماء الملفات الأصلية.

`images.json` يحتوي قائمة الصور، و`data.js` هو المكان الأسهل لتغيير بيانات الخدمات والمشاريع.

## أهم الصفحات
- الرئيسية
- متجر الخدمات
- الزهور
- الأشجار والنباتات
- الحدائق
- الصيانة
- طلباتي
- أعمالنا
- تواصل
- الخصوصية
- الشروط

## مهم
لا تغيّر اسم `index.html` ولا تنشئ مجلدًا إضافيًا فوق ملفات الموقع عند الرفع.
