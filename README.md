# Balqees Floral — GitHub Pages

هذه النسخة جاهزة للرفع على GitHub Pages.

- جميع الملفات في **مجلد واحد فقط** — لا يوجد مجلد `assets` أو مجلد صور داخل مجلد آخر.
- أسماء جميع الصور عشوائية لتجنب مشاكل الأسماء والمسارات.
- تمت إضافة صورتين جديدتين لأعمال **تنسيق الحدائق**.
- تمت إضافة خانة خدمة جديدة: **تنسيق الحدائق**.
- روابط Instagram / Facebook / TikTok / Snapchat موجودة داخل الموقع.
- الصفحة مضبوطة RTL بالعربية مع تحسين عرض الجوال ومنع تداخل النصوص.

## الرفع
ارفع `index.html` وكل ملفات الصور الموجودة معه في نفس المجلد داخل مستودع GitHub Pages.
