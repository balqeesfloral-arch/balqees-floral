# موقع بلقيس الورد — النسخة المحدّثة

نسخة HTML وCSS وJavaScript لتسليم الموقع التعريفي ورفعه على استضافة ملفات ثابتة، دون React أو خطوة بناء.

## التشغيل

- افتح `index.html` مباشرة للمعاينة.
- عند الرفع، ارفع جميع الملفات والصور معًا داخل المجلد نفسه.
- لا تغيّر أسماء الصور لأن الصفحة تستخدم مسارات نسبية لتعمل محليًا وعلى الاستضافة.
- في GitHub Pages أو الاستضافة الحالية، استبدل ملفات الموقع بمحتويات ZIP بعد حفظ نسخة احتياطية. يجب أن يكون `index.html` في الجذر مع `styles.css` و`app.js` والصور والخطوط.
- معاينة الملفات في تطبيق الملفات على الهاتف ليست بديلًا عن فتح الموقع في المتصفح بعد رفعه؛ قد لا تشغل المعاينة JavaScript أو الملفات المرتبطة.

## المزايا

- تصميم متجاوب للجوال والتابلت والكمبيوتر.
- واجهة عربية وإنجليزية.
- خط Noto Sans Arabic مضمن محليًا؛ رخصته في `FONT-LICENSE.txt`.
- أيقونات SVG مدمجة بلا مكتبات خارجية.
- معرض أعمال تفاعلي يضم 10 صور وطلب عرض سعر عبر واتساب.
- قسم باقات للمناسبات المحددة، دون المناسبات المستبعدة.
- بطاقة بيانات المؤسسة والسجل والرقم الضريبي.
- أزرار عائمة مرتبة فوق شريط التنقل في الجوال.
- ملف جهة اتصال قابل للحفظ ورمز QR جديد تم التحقق من قراءته.

## نطاق النسخة والتحقق

- نموذج الطلب يجهز رسالة واتساب ولا يخزن بياناتها. يجب على العميل إكمال الإرسال في واتساب.
- بطاقة المؤسسة تعريفية، وليست تحققًا حكوميًا أو توقيعًا إلكترونيًا أو آلية حماية عقود من التعديل.
- نجح فحص JavaScript ووجود الأصول والروابط الداخلية، و16 اختبارًا برمجيًا تشمل اللغات والقائمة والمعرض والنموذج والتخزين المعطل وبيانات التواصل.
- فحص QR والتحقق من سلامة قراءة جميع ملفات الصور نجحا.
- الاختبارات البرمجية استخدمت محاكاة DOM بلا عرض بصري؛ تعذر اختبار الشكل في متصفح الجوال والكمبيوتر بسبب قيد بيئة المعاينة. يُنصح بمراجعة العرض على الاستضافة قبل مشاركته مع العملاء.

تسجيل الدخول والحسابات والإدارة والمحاسبة ضمن خطة React المرتبطة بقاعدة بيانات آمنة، وليست جزءًا من هذه النسخة الثابتة. لم تُنشر هذه النسخة على موقع عام من خلال هذه المهمة.
