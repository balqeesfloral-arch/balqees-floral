# Balqees Floral — PRO MAX

نسخة موقع بلقيس للزهور والنباتات — مكة المكرمة.

## التحديثات في هذه النسخة
- إضافة 10 صور جديدة من أعمال بلقيس إلى معرض المشاريع في أماكنها المناسبة.
- إبقاء الصور القديمة مع الجديدة داخل **مجلد واحد فقط** بجانب `index.html`.
- استخدام أسماء عشوائية للصور الجديدة لتفادي مشاكل GitHub وحساسية أسماء الملفات.
- إنشاء نسخة شعار مقصوصة يظهر فيها الرمز فقط بدون كلمة «بلقيس» أسفل الشعار.
- تحديث صورة الـ Cover بقصّ يركز على الورود لتظهر بشكل أوضح.
- تحسين توزيع معرض الأعمال على الشاشات الكبيرة مع الحفاظ على العرض المتجاوب للجوال والتابلت.

## الملفات
- `index.html` — الموقع بالكامل.
- `Balqees-Contact.vcf` — بطاقة جهة الاتصال.
- جميع الصور في نفس المجلد مع الصفحة الرئيسية.
